Die Diagnostics • Numismatic / Forensic Framework

การวิเคราะห์พิจารณาพระแท้เหรียญเกจิคณาจารย์ไทยฯ กับวิธีการทางพิพิธภัณฑ์สำนักกษาปณ์ใช้ทั่วโลก

เมื่อไม่มีแม่พิมพ์ต้นแบบ เราจะพิสูจน์ได้อย่างไรว่าเหรียญมาจากแม่พิมพ์เดียวกัน?

บทคัดย่อ

การพิจารณาเหรียญพระเกจิคณาจารย์ไทยสามารถมองได้ทั้งในมิติของความแท้และความสัมพันธ์ของแม่พิมพ์ แต่สองคำถามนี้ไม่ใช่คำถามเดียวกัน บทความนี้เน้นประเด็นหลัง: หากไม่มีแม่พิมพ์ต้นแบบเหลืออยู่ เราจะศึกษาว่าเหรียญหลายเหรียญมีความสัมพันธ์กับแม่พิมพ์เดียวกันได้อย่างไร

แนวทางหนึ่งคือการศึกษาร่องรอยที่เกิดจากสภาพของแม่พิมพ์และถูกถ่ายทอดลงบนเหรียญ เช่น Die Polish Lines, Die Cracks, Die Pitting / Die Deterioration และ Die Clash Marks แล้วเปรียบเทียบตำแหน่ง รูปร่าง ทิศทาง และความต่อเนื่องของร่องรอยหลายบริเวณ โดยใช้ภาพที่ควบคุมพิกัดและการซ้อนภาพเป็นเครื่องมือช่วยตรวจสอบ

หลักการสำคัญ: ผลการเปรียบเทียบควรใช้เพื่อ “สนับสนุนหรือไม่สนับสนุนสมมติฐานเรื่องความสัมพันธ์ของแม่พิมพ์” ไม่ใช่ประกาศความแท้หรือความเป็นแม่พิมพ์เดียวกันจากตำหนิเพียงจุดเดียว

1. แยกสองคำถามออกจากกัน

Authenticity Assessmentประเมินว่าเหรียญมีลักษณะสอดคล้องกับเหรียญแท้ กระบวนการผลิต เนื้อโลหะ สภาพ และข้อมูลประกอบอื่นหรือไม่
Die Relationship Analysisศึกษาว่าเหรียญสองเหรียญหรือหลายเหรียญมีร่องรอยที่สอดคล้องกับแม่พิมพ์เดียวกันหรือไม่

การพบความสัมพันธ์ของแม่พิมพ์เป็นหลักฐานชนิดหนึ่งของการศึกษาเหรียญ แต่ไม่ได้ตอบคำถามทั้งหมดเรื่องอายุ แหล่งที่มา provenance หรือความแท้ของวัตถุโดยอัตโนมัติ

4. เมื่อไม่มีแม่พิมพ์ต้นแบบ

ให้เปลี่ยนวัตถุอ้างอิงจาก “แม่พิมพ์ → เหรียญ” เป็น “เหรียญ → เหรียญ → เหรียญ” โดยใช้เหรียญที่ยังหลงเหลือเป็นหลักฐานทางอ้อมของสภาพแม่พิมพ์

จุดแข็งอยู่ที่การตรวจสอบ หลายตำแหน่ง และหลายประเภทของ Micro-Features ไม่ใช่การตัดสินจาก “ตำหนิเด็ด” เพียงหนึ่งจุด

6. วิธีคิดแบบ A / B / C

สมมติว่ามีเหรียญสามตัวอย่าง การตรวจสอบควรดูว่าร่องรอยเฉพาะตำแหน่งยังคงสอดคล้องกันหรือไม่

บริเวณ Aพบเส้นหรือจุดที่มีตำแหน่งและรูปแบบสอดคล้องกัน
บริเวณ Bพบร่องรอยอีกชุดที่สอดคล้องกันโดยไม่อาศัยจุดเดียวกับบริเวณ A
บริเวณ Cตรวจสอบรอยแตกหรือรายละเอียดเฉพาะอื่น
ภาพรวมหลักฐานหลายบริเวณสนับสนุนสมมติฐานเดียวกันหรือไม่?
ไม่ใช่: “เหมือนกันหนึ่งจุด = แม่พิมพ์เดียวกัน”
แต่เป็น: “หลักฐานเฉพาะหลายตำแหน่งสอดคล้องกัน = เพิ่มน้ำหนักให้สมมติฐาน Same-Die”

8. Evidence Fusion: อย่าพึ่งหลักฐานชนิดเดียว

Die DiagnosticsPolish Lines, Cracks, Pitting, Clash และลักษณะเฉพาะอื่น
Geometryตำแหน่งและรูปร่างของรายละเอียดที่สัมพันธ์กับพิกัดเดียวกัน
Surface / Physicalข้อมูลพื้นผิว ขนาด น้ำหนัก ความหนาแน่น หรือการทดสอบทางกายภาพเมื่อเหมาะสม

กรอบ Triangulated Reliability ช่วยให้มองความน่าเชื่อถือเป็นการบรรจบกันของหลักฐานหลายชั้น ไม่ใช่ตัวเลขจากเครื่องมือเพียงตัวเดียว

9. DieForensics V17: จากหลักการสู่เครื่องมือ

DieForensics V17 เป็นต้นแบบที่นำแนวคิดข้างต้นมาเป็น workflow ได้แก่ IMAGE QUALITY → REGISTRATION SEARCH → ROBUST MATCHING → EVIDENCE FUSION → ENGINEERING / REPORT และมีโมดูลสำหรับ Polishing Scratches, Pitting, Die Cracks, Die Clash, Geometry และ Surface Texture

สถานะของเครื่องมือ: เป็น offline single-file prototype; automated registration, matching และ confidence เป็น heuristic และต้องผ่าน external validation ก่อนใช้ในงาน forensic หรือ commercial จริง ดังนั้นระบบนี้ควรทำหน้าที่เป็น “เครื่องมือช่วยตรวจสอบหลักฐาน” ไม่ใช่เครื่องรับรองพระแท้

10. ข้อจำกัด

  • ภาพที่เบลอ แสงไม่สม่ำเสมอ หรือกำลังขยายไม่เพียงพออาจทำให้ร่องรอยผิดเพี้ยน
  • Rotation, scale และ perspective ต้องได้รับการควบคุมหรือแก้ไขก่อนเปรียบเทียบ
  • ร่องรอยบนเหรียญอาจสึกหายหรือเปลี่ยนจากการใช้งาน การขัด หรือการกัดกร่อน
  • รอยกระแทกและรอยขูดภายหลังการผลิตต้องแยกจากร่องรอยที่เกิดจากแม่พิมพ์
  • ไม่ควรนำค่าความมั่นใจจาก prototype ไปตีความเป็นความน่าจะเป็นทางนิติวิทยาศาสตร์โดยไม่มี validation

11. ข้อสรุป

การไม่มีแม่พิมพ์ต้นแบบไม่ได้หมายความว่าไม่สามารถศึกษาความสัมพันธ์ของแม่พิมพ์ได้ แต่ต้องเปลี่ยนวิธีคิดจากการนำเหรียญไปเทียบกับแม่พิมพ์ มาเป็นการใช้ร่องรอยที่ถูกถ่ายทอดจากแม่พิมพ์บนเหรียญหลายเหรียญเป็นหลักฐานทางอ้อม

Die Polish Lines, Die Cracks, Die Pitting และ Die Clash Marks จึงมีคุณค่าเมื่อสามารถระบุตำแหน่งและตรวจสอบซ้ำได้ โดยเฉพาะเมื่อพบลักษณะสอดคล้องกันหลายบริเวณและมีหลักฐานชนิดอื่นสนับสนุน

ข้อสรุปทางวิธีวิทยา: ควรใช้ถ้อยคำว่า “หลักฐานสนับสนุนสมมติฐานว่าเหรียญมีความสัมพันธ์กับแม่พิมพ์เดียวกัน” มากกว่าการประกาศ “พิสูจน์ 100%” จากภาพหรือระบบอัตโนมัติเพียงอย่างเดียว
